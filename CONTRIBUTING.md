# Contributing

This repo is a set of plain-text skills for writing social posts. Small, focused fixes are welcome.

## Before you start

- Found a mistake or have a question? Open an [issue](https://github.com/nickspiz/social-post-skills/issues/new/choose) or start a [discussion](https://github.com/nickspiz/social-post-skills/discussions).
- Network limits and formatting change. If a number in a skill is out of date, say which one and link the platform's own documentation.
- Planning something bigger than a few dozen lines, such as a new network? Open an issue first so we can agree on the shape.

## Checking your change

There is no code to test. Read the files you changed. Check that the front matter has `name` and `description`, that the folder name matches `name`, and that every link works.

## Rules for the text

- Examples use made-up products. No real brands, people or numbers.
- No em dashes. Use a hyphen, a comma, a colon or two sentences.
- Say what to do, not how great the skill is.

## Pull requests

- One change per pull request.
- Say what changed and why, in plain English.
- Update the README if the change is visible to users.

By contributing you agree that your work is released under the MIT license.
